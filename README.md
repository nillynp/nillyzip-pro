## Τι κάνει το NillyZip Pro

- **Πλήρης Υποστήριξη Μορφών (Native Windows 11 Engine — 0 εξωτερικά DLLs):**
  - **Άνοιγμα & Περιήγηση (Virtual Folder Tree):** `.zip`, `.rar`, `.7z`, `.tar`, `.tar.gz` / `.tgz`, `.tar.xz` / `.txz`, `.tar.bz2`, `.tar.zst`, `.gz`, `.cab`, `.iso`.
  - **Δημιουργία Συμπιεσμένων Αρχείων:** `.zip` (Fastest / Optimal / Store 0%), `.7z`, `.tar.gz`, `.tar.xz`, `.tar.zst` με **Drag & Drop** αρχείων ή ολόκληρων φακέλων.
  - **Προσθήκη & Διαγραφή αρχείων** απευθείας μέσα σε υπάρχοντα `.zip`.
- **Έξυπνη Εξαγωγή & Drag & Drop (Smart Extract — Zero Mess!):**
  - **Drag & Drop ΕΞΩ σε οποιονδήποτε φάκελο / Desktop** (όπως στο WinRAR & 7-Zip!) + **`Ctrl+C` → `Ctrl+V`** απευθείας στον Windows Explorer — σύρεις μεμονωμένα αρχεία ή ολόκληρους φακέλους από μέσα από `.zip / .rar / .7z / .tar` κατευθείαν στον φάκελο που θες!
  - Αν ένα αρχείο περιέχει πολλά σκόρπια αρχεία στη ρίζα, το **Smart Extract** δημιουργεί αυτόματα έναν καθαρό υποφάκελο με το όνομα του αρχείου για να μη γεμίσει η Επιφάνεια Εργασίας σου!
  - Εξαγωγή Όλων (`Ctrl+E`), Εξαγωγή Επιλεγμένων (δεξί κλικ), ή Έξυπνη Εξαγωγή Εδώ.
  - **Ενσωματωμένη Προστασία Zip-Slip:** μπλοκάρει αυτόματα κακόβουλες διαδρομές (`../`, drive-letter paths) πριν την αποσυμπίεση.
- **Άμεση Προεπισκόπηση & Έλεγχος Ακεραιότητας (χωρίς αποσυμπίεση!):**
  - Προεπισκόπηση **κειμένου / κώδικα** (`.txt`, `.json`, `.xml`, `.csv`, `.html`, `.md`, `.cs`, `.js`, `.css`, `.ps1`, `.log`) και **εικόνων** (`.png`, `.jpg`, `.gif`, `.bmp`) απευθείας μέσα από το `.zip`.
  - **Έλεγχος CRC & SHA-256 (`✓ Έλεγχος`):** επαληθεύει όλα τα περιεχόμενα του αρχείου και υπολογίζει το **SHA-256 hash** με 1 κλικ αντιγραφή.
- **Ενσωμάτωση στον Windows Explorer (Zero Admin — HKCU):**
  - Δεξί κλικ σε οποιοδήποτε αρχείο/φάκελο → **Συμπίεση σε .ZIP (NillyZip Pro)**.
  - Δεξί κλικ σε `.zip / .rar / .7z / .tar` → **Εξαγωγή εδώ (NillyZip Pro)** ή **Άνοιγμα με NillyZip Pro**.
- **Prepress Dark & Light Studio UI:**
  - Σκοτεινό & φωτεινό θέμα, live αναζήτηση (`Ctrl+F`) χωρίς ευαισθησία στους ελληνικούς τόνους, breadcrumb πλοήγηση, ~12–20 MB RAM ενεργό / **0 MB** κλειστό.

## Εγκατάσταση στα Windows 10/11 (100% Portable · Χωρίς Admin)

1. Κατέβασε το **`NillyZip-Pro-v1.2.2-Portable.zip`** από τα [GitHub Releases](https://github.com/nillynp/nillyzip-pro/releases) και αποσυμπίεσέ το (π.χ. `C:\Tools\NillyZipPro`).
2. Τρέξε με διπλό κλικ το **`Install_NillyZipPro.bat`** *(δεν απαιτεί δικαιώματα Administrator!)*.
   - Μεταγλωττίζει αυτόματα το 100% native **`NillyZipPro.exe` (~75 KB)**.
   - Προσθέτει το δεξί κλικ στον Windows Explorer, εγγράφει το `NillyZip Pro` στις Προεπιλεγμένες Εφαρμογές για `.zip / .7z / .rar / .tar` και δημιουργεί συντομεύσεις σε Desktop & Start Menu.
3. Για να ανοίγουν όλα τα `.zip / .rar / .7z` αυτόματα με διπλό κλικ, τρέξε το **`Set_Default_NillyZipPro.bat`**.

### Απεγκατάσταση
Τρέξε το **`Uninstall_NillyZipPro.bat`** — αφαιρεί καθαρά μόνο τις συντομεύσεις και τις εγγραφές `HKCU` χωρίς να αγγίξει κανένα αρχείο σου.
